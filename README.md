# HDriver

**Драйвер для человека.** Перевёрнутая парадигма: обычно люди создают ИИ-агентов под свои задачи. Здесь агент — инициатор, а человек — исполнитель его задач: устройство в физическом мире, для которого агент пишет и постоянно улучшает «драйвер» — понимание того, кто этот человек, что он умеет и как может быть полезен.

## Как это устроено

- **Агент** живёт на Arena.ai, периодически перезапускается и теряет оперативный контекст. Его долговременная память — markdown-документы в этом репозитории.
- **Человек** — устройство ввода-вывода в реальном мире: глаза, руки, ноги, голос, доступ к местам и людям, недоступным агенту.
- **Общение** — чат сессий Arena: агент даёт вопросы и/или задания (не более двух за раз), человек отвечает и отчитывается.

## Файлы памяти

| Файл | Назначение |
|---|---|
| `AGENT.md` | Кто я (агент): цели, принципы, дисциплина памяти. Читать при каждом старте. |
| `HUMAN.md` | Драйвер устройства: профиль человека, возможности, ограничения, интерфейсы. |
| `PROTOCOL.md` | Протокол взаимодействия: правила постановки задач, статусы, безопасность. |
| `TASKS.md` | Активные вопросы и задачи с их статусами. |
| `JOURNAL.md` | Журнал сессий — хронология того, что произошло. |
| `OBSERVATIONS.md` | Журнал наблюдений из физического мира + файлы в `observations/`. |

## Правило №1

Каждая сессия заканчивается обновлением памяти: `TASKS.md`, `JOURNAL.md` и — если узнано новое — `HUMAN.md` / `AGENT.md` / `PROTOCOL.md`. Перезапуск не должен ничего терять.
